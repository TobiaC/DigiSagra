# DigiSagra

Questa è una collezione di programmi utili per lo svolgimento di una sagra. La sagra di riferimento per gli sviluppi è il ferragosto Torsese a Torsa di Pocenia.
Attualmente la collezione comprende:

- Pesca: programma che mette a disposizione una semplice interfaccia per verificare quale premio è associato a un dato numero di biglietto nella pesca di beneficienza
- Tombola: programma che permette di avere un tabellone digitale per la tombola e di condividerlo in rete locale in modo da poterlo visualizzare in più postazioni.
